1. Local 64-bit Compilation

The original C source files (version 0.10) have been adapted for standard 64-bit builds, and an automated build script has been created for the Microsoft Visual C++ (MSVC) toolchain.

To compile the engine directly from source code, simply run from Command Prompt or PowerShell: 

build.bat

The script automatically detects the Visual Studio installation (e.g. Visual Studio Community) via vswhere, configures the 64-bit environment (vcvars64.bat), and generates the optimized native binary: 

bin\LaMoSca.exe (Native x64 executable, ~45 KB)

2. Interfacing LaMoSca with a GUI: Arena Chess

Since version 0.10 implements the standard WinBoard / XBoard protocol, it can be played immediately on a modern graphical board using the free Arena Chess GUI.

Step 1: Download Arena Chess

From the official website playwitharena.de, download the portable (no-install) archive Arena 3.5.1 ZIP (17 MB). Simply extract the ZIP into any directory of your choice and launch Arena.exe.

Step 2: Launching Arena Chess

When opened, Arena displays the primary chessboard alongside the engine analysis and clock panels:

Step 3: Registering the LaMoSca Engine

To add LaMoSca to Arena's installed engines list:

  1. In the main menu, navigate to Engines → Manage... (or press F11).
  2. Switch to the Details tab and click New.
  3. Select the executable file: ...\lamosca\bin\LaMoSca.exe.
  4. In the Type drop-down menu, set the protocol to Winboard.
  5. The Name ("LaMoSca") and Author ("Pietro Valocchi") fields are recognized automatically.
  6. Click Apply and then OK.

LaMoSca is now installed and ready to play games on Arena!

Step 4: Starting the First Game

To watch LaMoSca think and calculate moves on the graphical board:

  1. In the main menu, select Game → New Game to set up the starting position.
  2. To play as White: simply make your opening move on the board by dragging a piece with the mouse (for instance, moving the pawn to e4 or d4). As soon as you release the piece, LaMoSca (controlling Black) analyzes the position and responds automatically!
  3. To have LaMoSca play as White: select from the menu Engines → Move Now! (or click the green arrow icon on the toolbar). The engine computes its opening variant, makes its first move as White, and waits for your response.
  4. Real-time search analysis: while the engine is calculating, the bottom analysis window in Arena shows the current search depth (ply), total nodes evaluated, and the anticipated continuation (Principal Variation).

3. Development Roadmap Ahead

With the 64-bit build system verified and WinBoard integration working smoothly in Arena, the next development milestones include:

  • UCI Protocol Support: full compliance with the modern Universal Chess Interface (compatible with CuteChess, En-Croissant, Lichess bots).
  • Complete Ruleset & Perft Validation: full castling rights, en passant captures, and underpromotions.
  • Transposition Table & Zobrist Hashing: caching previously analyzed game states to dramatically prune redundant subtree exploration.
  • Time Management: dynamically allocating search time based on remaining clock and increments.
